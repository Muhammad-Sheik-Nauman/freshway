# 🔬 Experiment EXP-001: MobileNetV2 Two-Phase Fish Freshness Classifier Baseline

- **Experiment ID:** EXP-001
- **Date:** Baseline (Pre-August 2026 / Documented 2026-08-25)
- **Author / Engineer:** Not recorded in the repository
- **Model Family:** MobileNetV2 (ImageNet Pretrained)
- **Target Task:** 3-Class Categorical Fish Eye Freshness Classification (`fresh`, `highly_fresh`, `not_fresh`)

---

## 1. Experiment Question
Can a two-phase transfer learning approach with ImageNet-pretrained MobileNetV2, combined with Sklearn-style class weighting and correct $[-1, 1]$ preprocessing normalization, be configured for training on an imbalanced fish eye dataset?

---

## 2. Hypothesis
- **H1:** Using native MobileNetV2 `preprocess_input` (scaling $[-1, 1]$) instead of $[0, 1]$ scaling prevents feature map distortion from pretrained ImageNet weights.
- **H2:** Computing inverse frequency class weights will prevent the model from biasing toward the majority class.
- **H3:** Freezing the base during Phase 1 ($\text{LR} = 5\times 10^{-4}$) allows the dense classification head to stabilize before fine-tuning the top 50 convolutional layers in Phase 2 ($\text{LR} = 1\times 10^{-5}$).

---

## 3. Dataset Configuration
- **Input Size:** $224 \times 224 \times 3$
- **Train Directory:** `server/data/train/` (80% split)
- **Validation Directory:** `server/data/val/` (20% split)
- **Classes:** `fresh`, `highly_fresh`, `not_fresh`
- **Augmentation Pipeline:**
  - `rotation_range`: 40°
  - `width_shift_range`: 0.25
  - `height_shift_range`: 0.25
  - `shear_range`: 0.2
  - `zoom_range`: 0.3
  - `horizontal_flip`: True
  - `vertical_flip`: True
  - `brightness_range`: $[0.7, 1.3]$
  - `fill_mode`: `"nearest"`

---

## 4. Model Architecture & Hyperparameters
- **Base Model:** `tf.keras.applications.MobileNetV2(include_top=False, weights='imagenet', input_shape=(224, 224, 3))`
- **Classification Head:**
  - `GlobalAveragePooling2D()`
  - `Dense(512, activation='relu')` + `BatchNormalization()` + `Dropout(0.4)`
  - `Dense(256, activation='relu')` + `BatchNormalization()` + `Dropout(0.3)`
  - `Dense(128, activation='relu')` + `BatchNormalization()` + `Dropout(0.2)`
  - `Dense(3, activation='softmax')`
- **Loss:** `categorical_crossentropy`
- **Batch Size:** 32
- **Phase 1 Epochs:** 20
- **Phase 2 Epochs:** 40 (the last 50 base-model layers are trainable)
- **Callbacks:**
  - `EarlyStopping(monitor='val_accuracy', patience=10, restore_best_weights=True)`
  - `ReduceLROnPlateau(monitor='val_loss', factor=0.5, patience=4, min_lr=1e-7)`
  - `ModelCheckpoint(filepath='server/models/freshness_model_best.keras', monitor='val_accuracy', save_best_only=True)`
  - `SaveProgressCallback` (JSON state tracking in `training_progress.json`)
