# 🔬 Experiment EXP-001: MobileNetV2 Two-Phase Fish Freshness Classifier Baseline

- **Experiment ID:** EXP-001
- **Date:** Baseline (Pre-August 2026 / Benchmarked 2026-09-04)
- **Model Family:** MobileNetV2 (ImageNet Pretrained)
- **Target Task:** 3-Class Categorical Fish Eye Freshness Classification (`fresh`, `highly_fresh`, `not_fresh`)
- **Status:** Completed Baseline (Measured Accuracy: **69.0%**)

---

## 1. Experiment Question
Can a two-phase transfer learning approach with ImageNet-pretrained MobileNetV2, combined with Sklearn-style class weighting and $[-1, 1]$ preprocessing normalization, achieve high classification accuracy on an imbalanced fish eye dataset?

---

## 2. Hypothesis
- **H1:** Using native MobileNetV2 `preprocess_input` (scaling $[-1, 1]$) instead of $[0, 1]$ scaling prevents feature map distortion from pretrained ImageNet weights.
- **H2:** Computing inverse frequency class weights will prevent the model from biasing toward the majority class.
- **H3:** Freezing the base during Phase 1 ($\text{LR} = 5\times 10^{-4}$) allows the dense classification head to stabilize before fine-tuning the top 50 convolutional layers in Phase 2 ($\text{LR} = 1\times 10^{-5}$).

---

## 3. Dataset Configuration
- **Input Size:** $224 \times 224 \times 3$
- **Train Directory:** `server/data/train/` (80% split)
- **Validation Directory:** `server/data/val/` (20% split)
- **Classes:** `fresh`, `highly_fresh`, `not_fresh`
- **Augmentation Pipeline:**
  - `rotation_range`: 40°
  - `width_shift_range`: 0.25
  - `height_shift_range`: 0.25
  - `shear_range`: 0.2
  - `zoom_range`: 0.3
  - `horizontal_flip`: True
  - `vertical_flip`: True
  - `brightness_range`: $[0.7, 1.3]$
  - `fill_mode`: `"nearest"`

---

## 4. Model Architecture & Hyperparameters
- **Base Model:** `tf.keras.applications.MobileNetV2(include_top=False, weights='imagenet', input_shape=(224, 224, 3))`
- **Classification Head:**
  - `GlobalAveragePooling2D()`
  - `Dense(512, activation='relu')` + `BatchNormalization()` + `Dropout(0.4)`
  - `Dense(256, activation='relu')` + `BatchNormalization()` + `Dropout(0.3)`
  - `Dense(128, activation='relu')` + `BatchNormalization()` + `Dropout(0.2)`
  - `Dense(3, activation='softmax')`
- **Loss:** `categorical_crossentropy`
- **Batch Size:** 32
- **Phase 1 Epochs:** 20
- **Phase 2 Epochs:** 40 (last 50 base-model layers trainable, unfreezing BN)

---

## 5. Measured Experimental Results & Artifacts

- **Validation Accuracy:** **69.0%**
- **Validation Loss:** ~0.84
- **Artifacts Produced:**
  - `server/models/freshness_model_best.keras` (26,222,899 bytes)
  - `server/models/freshness_model_final.keras` (26,222,899 bytes)

---

## 6. Diagnostic Analysis (Why Accuracy Capped at 69%)

1. **Batch Normalization Destabilization in Phase 2:**
   Unfreezing the base model without locking Batch Normalization layers caused ImageNet running mean and variance to be corrupted by small-batch (32) statistics, degrading validation convergence.
2. **Head Variance Shift & Overparameterization:**
   The 3-layer Dense head added 820k parameters. Alternating ReLU $\rightarrow$ BatchNorm $\rightarrow$ Dropout introduced train/test variance shift.
3. **Biological Distortion in Augmentation:**
   `fill_mode="nearest"` produced streaked borders resembling corneal cataracts, while $\pm 30\%$ brightness scaling masked pupil translucency.
4. **Anisotropic Aspect-Ratio Squashing:**
   Resizing non-square images directly to $224 \times 224$ warped spherical eyeballs into ovals.

## 8. Dataset and Artifact Provenance Reconciliation (2026-09-04)

**Investigation only — no training or evaluation performed.**

- The original `server/data/train/` and `server/data/val/` directories referred to above are absent. No split manifest, random seed, per-class split counts, training history, or saved evaluation report was found.
- The newly supplied source tree is a near-complete copy of the Mendeley FFE source structure: eight species × three freshness levels = 24 folders. It has 4,390 JPEG files, versus 4,392 images published for Mendeley Data DOI `10.17632/xzyx7pbr3w.1`; the two-image difference is `Nibea Albiflora - Not Fresh` (121 local, 123 published).
- This source tree cannot be supplied directly to the documented three-class trainer because it has no `train`/`val` split and does not contain the required direct child folders `fresh`, `highly_fresh`, and `not_fresh`.
- `freshness_model_best.keras` exists and its 26,222,899-byte size matches the artifact size recorded above. Its inspected head is `Dense(256) → BatchNorm → Dropout(0.50) → Dense(128) → BatchNorm → Dropout(0.30) → Dense(3)`, not the documented `512 → 256 → 128` head. Accordingly, the ~69% result remains a historical documented claim, not a result that can presently be independently verified.

**Conclusion:** The supplied images strongly appear to be the intended public source dataset, but there is insufficient retained provenance to prove that they are the exact pre-split input used for this baseline or to reproduce its 69.0% result.
